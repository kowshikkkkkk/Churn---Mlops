#  Customer Churn MLOps Pipeline

An end-to-end Machine Learning Operations (MLOps) pipeline that predicts customer churn — built locally using Python, MLflow, FastAPI, and Evidently AI.

---

##  What is this project?

Customer churn means customers stopping use of a service. This project builds a full ML pipeline that:
- Trains a machine learning model to predict if a customer will churn
- Tracks every experiment so you can compare model runs
- Serves the model as a REST API so any app can use it
- Monitors incoming data for drift and automatically retrains the model when needed

---

##  What is MLOps?

MLOps (Machine Learning Operations) is the practice of deploying and maintaining ML models in production reliably. Think of it as DevOps but for machine learning — it connects data science with real-world deployment.

##  Project Structure
```
churn-mlops/
├── data/               # Raw dataset (not tracked by Git)
├── models/             # Saved model file
├── notebooks/          # For exploration and EDA
├── reports/            # Drift reports generated by Evidently
├── src/
│   ├── preprocess.py   # Loads and cleans the dataset
│   ├── train.py        # Trains the model and logs to MLflow
│   ├── predict.py      # Loads model and runs inference
│   ├── monitor.py      # Detects data drift using Evidently AI
│   └── retrain.py      # Auto-retrains model when drift is detected
├── api/
│   └── main.py         # FastAPI app serving predictions
├── requirements.txt
└── README.md
```

##  How to Run This Project

### 1. Clone the repo
```bash
git clone https://github.com/kowshikkkkkk/Churn---Mlops.git
cd Churn---Mlops
```

### 2. Create and activate virtual environment
```bash
python -m venv venv
source venv/Scripts/activate  # Windows
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Download the dataset
Download the Telco Customer Churn dataset from Kaggle and place it in the `data/` folder:
 https://www.kaggle.com/datasets/blastchar/telco-customer-churn

### 5. Train the model
```bash
python src/train.py
```

### 6. View experiments in MLflow
```bash
mlflow ui
```
Open http://localhost:5000 in your browser.

### 7. Start the prediction API
```bash
uvicorn api.main:app --reload
```
Open http://localhost:8000/docs to test the API interactively.

### 8. Run drift monitoring and auto-retrain
```bash
python src/retrain.py
```

##  Pipeline Flow
```
Raw Data → Preprocess → Train + Track (MLflow) → Save Model
                                                      ↓
                                              Serve via FastAPI
                                                      ↓
                                         Monitor for Data Drift (Evidently)
                                                      ↓
                                         Drift Detected? → Auto Retrain
```
